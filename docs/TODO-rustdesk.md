# RustDesk 实施清单

按 [技术设计第 6 节](rustdesk-technical-design.md#6-实施顺序与放行证据)推进。

## P0 解耦

- [x] 移除旧远控的运行时感知、会话判定和诊断。替换为独立会话状态及只读环境自检。
- [x] 隔离 Bundle ID、应用名称、配置与日志、虚拟屏身份。派生版发布与应用内更新默认关闭。
- [x] `scripts/snug check` 通过（macOS 26.5 SDK、原生 SwiftPM 构建方式并加载本机 Testing 插件）。384 项 Swift、15 项 Python 测试通过。arm64 / x86_64 开发包通过 ad-hoc 签名检查。
- [ ] 与原版实机并装，分别授权，核对配置、屏幕和更新地址。

## M0 单手机

- [x] 菜单栏手动开始和结束伴侣会话，复用选型、虚拟屏、窗口铺满与字号恢复。临时主屏随会话恢复。
- [x] 用样本测试空闲、重复、过期、未知、重连和手动结束。手势引擎支持取消正在进行的选字和惯性滚动。
- [ ] 采集手机通过自建服务连入、切屏、断开和重连的证据。服务器日志中的连接打开与关闭反映传输状态，需要验证能否识别已授权的桌面会话，并排除空闲、拒绝连接及文件传输。
- [ ] 对照触摸、虚拟鼠标和本机鼠标的事件来源。当前使用原生输入，等来源可靠后再启用翻译。

## M1 多屏与恢复

- [x] 临时主屏前持久化原排布，启动和显示拓扑变化时按在线显示器身份尝试恢复。用 fake 验证保存失败、恢复重试和重复调用。
- [ ] 真机验证四档显示、工具栏遮挡、其他虚拟屏共存、热拔屏及强杀后恢复。手机按设备比例建屏，竖屏最大比例受虚拟屏像素上限约束。

## M2 分发

- [x] 提供 `scripts/snug rd-check` 检查 RustDesk 版本、辅助功能、录屏和在线显示器。当前会话判断显示为未知。
- [ ] 接入已验证的会话信号后补齐自检的空闲与活动状态。在干净系统验证 Developer ID 签名、公证、自有渠道升级及配置保留。

## M3 可选

- [ ] 根据 M0 / M1 实际使用结果决定是否立项。
